# Maintainer review: contradictions in the skill

Use this before a release, or when asked to review the article-forge skill (or a copy of it) for contradictions. It is advisory: report, never edit.

1. Read `SKILL.md` and every file in `references/` of the skill under review, in full.
2. List every pair of instructions that cannot both be followed. Typical places: what needs the user's approval, what is written to `profile/`, when to stop and ask, and what a file must or must not contain.
3. For each contradiction, quote both instructions, name both files, and say which one the non-negotiable rules in `SKILL.md` support.
4. Also list instructions that point to a file or step that does not exist.
5. If you find nothing, say so plainly. Do not invent findings to fill the report.
